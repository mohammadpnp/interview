# PHP Core + OOP Notes

## هدف
مرور مبانی PHP که در مصاحبه‌های Laravel هم پیش‌نیاز اصلی هستند.

## مباحث کلیدی
- تفاوت `==` و `===` بسیار مهم است (type juggling).
- lifecycle یک request در PHP با مدل stateless طراحی را شکل می‌دهد.
- OOP اصولی: encapsulation، abstraction، inheritance، polymorphism.
- SOLID را pragmatic استفاده کن، نه شعاری.
- exception handling باید لایه‌بندی‌شده باشد؛ expose خطا به کاربر محدود باشد.
- autoloading با Composer و PSR-4 پایه معماری تمیز است.
- immutability نسبی برای DTOها در سیستم‌های حساس مفید است.

## نکات مصاحبه‌ای
- مثال واقعی از refactor کد قدیمی به ساختار maintainable بیاور.
- در مورد trade-off بین سادگی و abstraction صحبت کن.

## تمرین سریع
- یک ماژول کوچک با interface + dependency inversion در PHP پیاده کن.

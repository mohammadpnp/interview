# الگوی رایج مصاحبه در شرکت‌هایی شبیه دیجی‌کالا

## تمرکز اصلی
- معماری سرویس‌محور و طراحی API قابل اتکا
- تسلط بر دیتابیس، ایندکس، Query Optimization
- طراحی سیستم برای Domainهای پیچیده (Order، Payment، Inventory)

## مراحل رایج
1. ارزیابی رزومه و مهارت‌های اعلام‌شده
2. مصاحبه فنی مبتنی بر تجربه واقعی پروژه
3. مصاحبه معماری/طراحی سیستم
4. بررسی تناسب تیمی و رفتاری

## سوالات پرتکرار
- چگونه از N+1 Query جلوگیری می‌کنید؟
- برای موجودی کالا در ترافیک بالا چه مدلی پیشنهاد می‌دهید؟
- چگونه API Versioning را مدیریت می‌کنید؟
- چه زمان Transaction سنگین لازم است و چه زمان Eventual Consistency؟
- چگونه Failover را برای سرویس‌های کلیدی طراحی می‌کنید؟

## انتظار در پاسخ
- تمرکز روی سناریوهای واقعی کسب‌وکار
- توجه به Cost/Performance همزمان
- طراحی قابل توسعه، نه فقط قابل اجرا

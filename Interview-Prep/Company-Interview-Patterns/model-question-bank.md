# بانک سوالات مدل شرکت‌های بزرگ ایرانی

## سبک سوالات شبیه اسنپ (فشار روی Scale و Reliability)
1. یک سرویس Ride Matching با latency پایین چطور طراحی می‌کنی؟
2. اگر Redis از دسترس خارج شد، fallback سیستم چیست؟
3. چگونه جلوی double charge در پرداخت را می‌گیری؟
4. در ترافیک ناگهانی (Spike) چه مکانیزم‌هایی فعال می‌کنی؟
5. اگر یک dependency کند شود، چطور از سرایت خطا جلوگیری می‌کنی؟

## سبک سوالات شبیه دیجی‌کالا (فشار روی Domain و Data)
1. سیستم inventory با همزمانی بالا چطور طراحی می‌شود؟
2. برای سفارش، چه زمانی transaction محلی کافی نیست؟
3. چگونه جستجوی محصول (ES) را با DB همگام نگه می‌داری؟
4. اگر query order history کند شد، چه مسیر بهینه‌سازی داری؟
5. APIهای عمومی مارکت‌پلیس را چگونه versioning می‌کنی؟

## سبک سوالات شبیه همکاران سیستم (فشار روی پایداری و کیفیت)
1. چگونه domain مالی را مدل می‌کنی تا خطای محاسباتی کم شود؟
2. برای refactor ماژول قدیمی چه برنامه‌ای می‌چینی که regression کم شود؟
3. چگونه Business Rule را از Controller جدا و تست‌پذیر می‌کنی؟
4. اگر requirement مبهم بود، تحلیل و validation را چطور پیش می‌بری؟
5. در سیستم ERP، audit trail را چگونه پیاده‌سازی می‌کنی؟

## سوالات رفتاری فنی (تقریبا مشترک)
1. سخت‌ترین باگی که حل کردی چه بود و مسیر حل چه بود؟
2. زمانی که deadline نزدیک بود، چه trade-offهایی انجام دادی؟
3. اختلاف فنی با هم‌تیمی را چطور مدیریت کردی؟
4. نمونه‌ای از تصمیم اشتباه فنی خودت و درس آن را بگو.
5. چطور performance کار خودت را اندازه‌گیری و بهبود می‌دهی؟

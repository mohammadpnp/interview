# Message Queues Interview Questions

## پایه
1. queue چه مشکلی را حل می‌کند؟
2. تفاوت pub/sub و queue چیست؟
3. چرا idempotency برای consumer مهم است؟

## متوسط
1. چگونه retry policy طراحی می‌کنی؟
2. DLQ چیست و چه زمانی استفاده می‌شود؟
3. message ordering را چگونه مدیریت می‌کنی؟
4. چه زمانی async processing بدتر از sync است؟

## پیشرفته
1. outbox pattern را با مثال واقعی توضیح بده.
2. چگونه lag مصرف‌کننده را کاهش می‌دهی؟
3. برای پیام‌های poison چه strategy داری؟
4. چگونه integrity داده بین DB و broker را تضمین نسبی می‌دهی؟

سؤال 5 تفاوت array و slice در Go چیست؟

جواب پیشنهادی

  • array اندازه ثابت دارد و value type است؛ slice یک view روی underlying array است.
  • slice شامل pointer، len و cap است.
  • پاس دادن slice، header را copy می‌کند ولی underlying array مشترک می‌ماند.
  • append ممکن است روی همان array بنویسد یا array جدید allocate کند.
s := []int{1,2,3}
a := s[:2]
a = append(a, 9) // ممکن است روی همان underlying array اثر بگذارد

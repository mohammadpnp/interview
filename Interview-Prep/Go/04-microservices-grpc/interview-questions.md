# Microservices + gRPC Interview Questions

## پایه
1. gRPC چه مزایایی نسبت به REST دارد؟
2. تفاوت unary و streaming RPC چیست؟
3. deadline در gRPC چه کاربردی دارد؟

## متوسط
1. backward compatibility در Protobuf را چگونه حفظ می‌کنی؟
2. چگونه idempotency را در endpointهای حساس پیاده می‌کنی؟
3. چه زمان synchronous call بد است و باید async/event استفاده کرد؟
4. چگونه service discovery را طراحی می‌کنی؟

## پیشرفته
1. cascading failure چیست و چگونه مهار می‌شود؟
2. برای یک call chain چندمرحله‌ای چه retry strategy پیشنهاد می‌کنی؟
3. چگونه distributed tracing را در میکروسرویس‌ها اجرا می‌کنی؟
4. API Gateway چه زمانی ارزش دارد و چه زمانی bottleneck می‌شود؟

# نقشه راه آمادگی مصاحبه بک‌اند (Go + PHP)

این ساختار بر اساس رزومه شما و مدل مصاحبه شرکت‌های بزرگ ایرانی (مثل اسنپ، دیجی‌کالا، همکاران سیستم و شرکت‌های مشابه) طراحی شده است.

## ساختار
- `Go/`: مسیر کامل آمادگی مصاحبه Go Backend
- `PHP/`: مسیر کامل آمادگی مصاحبه PHP/Laravel Backend
- `Company-Interview-Patterns/`: الگو و سبک مصاحبه شرکت‌های هدف
  - `model-question-bank.md`: بانک سوالات مدل شرکت‌های بزرگ
  - `job-market-tech-map-jabinja-jobvision.md`: تکنولوژی‌های پرتکرار استخراج‌شده از آگهی‌ها

## روش استفاده پیشنهادی (۵ هفته)
1. هفته ۱: مبانی زبان + دیتابیس + API Design
2. هفته ۲: Concurrency/Microservices + Testing
3. هفته ۳: Docker/Kubernetes + System Design + Performance/Security
4. هفته ۴: Kafka/RabbitMQ + GraphQL + CI/CD + Cloud/IaC
5. هفته ۵: مرور سوالات سناریویی و اجرای Mock Interview

## نحوه مطالعه هر موضوع
1. ابتدا `notes.md` را بخوانید.
2. سپس `interview-questions.md` را بدون نگاه به جواب پاسخ دهید.
3. بعد از تمرین، با `interview-answers.md` پاسخ خودتان را مقایسه کنید.
4. برای هر سوال، پاسخ ۲ تا ۵ دقیقه‌ای تمرین کنید.
5. برای هر موضوع حداقل یک مثال واقعی از تجربه خودتان آماده کنید.

## نکته مهم مصاحبه شرکت‌های بزرگ
- فقط حفظ مفاهیم کافی نیست؛ توانایی تحلیل Trade-off مهم‌تر است.
- برای هر تکنولوژی که در رزومه آمده، یک تجربه عملی قابل توضیح آماده داشته باشید.
- در پاسخ‌ها، ساختار `مسئله -> تصمیم -> نتیجه` را رعایت کنید.
